# Firebase Auth Lab

**CSC 4360 Mobile App Development, Section B: In-Class Activity #13B**
Flutter app with Firebase Authentication: register, sign in, sign out, profile email display, and password update.

## Features

- **Register and sign in** with email and password, using Firebase Authentication.
- **Auth-state routing:** a `StreamBuilder` on `authStateChanges()` shows the profile for signed-in users and the sign-in screen otherwise. Sessions are restored when the app reopens.
- **Profile screen** showing the signed-in email, with **Sign out**.
- **Change password** with a re-authenticate-and-retry path for `requires-recent-login`.
- **Validation:** email format check and a 6-character password baseline before any request is sent.
- **Loading and error feedback:** spinner on the button, fields disabled during requests, and safe, human-readable error messages (raw exception text is never shown).

## Project structure

```
lib/
  main.dart                      Initializes Firebase, then runApp()
  firebase_options.dart          Generated by `flutterfire configure`
  services/
    auth_service.dart            All Firebase Auth calls + error-message mapping
  screens/
    auth_gate.dart               Chooses the screen from auth state
    auth_screen.dart             Register / sign-in form
    profile_screen.dart          Email, sign out, change password
docs/screenshots/                Test evidence images
```

Design rule: widgets never call `FirebaseAuth` directly; everything goes through `AuthService`.

## Error messages

`AuthService.friendlyError` maps Firebase error codes to safe messages:

| Firebase code | Message shown |
|---|---|
| `invalid-email` | That email address does not look valid. |
| `email-already-in-use` | An account already exists for that email. Try signing in. |
| `weak-password` | Password is too weak. Use at least 6 characters. |
| `user-not-found`, `wrong-password`, `invalid-credential` | Incorrect email or password. |
| `too-many-requests` | Too many attempts. Please wait a moment and try again. |
| `network-request-failed` | Network problem. Check your connection and try again. |
| `requires-recent-login` | Prompts for the current password, then retries. |
| anything else | Something went wrong. Please try again. |

Credential errors share one message on purpose, so the app does not reveal which emails have accounts.
